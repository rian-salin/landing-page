# Landing Page — Pack de Figurinhas

Feita com Next.js (App Router) + TypeScript.

```bash
npm install
npm run dev     # http://localhost:3000
```

- Textos e preços: `app/page.tsx` (arrays no topo do arquivo)
- Links de checkout: constantes `CHECKOUT_BASICO` / `CHECKOUT_PREMIUM` em `app/page.tsx`
- Estilos: `app/globals.css`
- Imagens: `public/img/` (veja `public/img/LEIA-ME.md`)
